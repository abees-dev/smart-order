# Internationalization (i18n) Setup

This project supports multiple languages using `react-i18next`. Currently configured languages:

- **Vietnamese (vi)** - Default language
- **English (en)**

## Usage

### Using translations in components

```tsx
import { useTranslation } from "react-i18next";

function MyComponent() {
  const { t } = useTranslation();

  return (
    <div>
      <h1>{t("app.title")}</h1>
      <p>{t("app.description")}</p>
    </div>
  );
}
```

### Language Switcher

The `LanguageSwitcher` component allows users to change languages:

```tsx
import { LanguageSwitcher } from "@/components/language-switcher";

function Header() {
  return (
    <div className="flex justify-between">
      <div>Content...</div>
      <LanguageSwitcher />
    </div>
  );
}
```

## File Structure

```
src/
├── lib/
│   └── i18n.ts              # i18n configuration
├── locales/
│   ├── en/
│   │   └── common.json      # English translations
│   └── vi/
│       └── common.json      # Vietnamese translations
├── components/
│   └── language-switcher.tsx # Language switcher component
├── hooks/
│   └── use-document-title.ts # Hook for document title management
└── types/
    └── i18next.d.ts         # TypeScript definitions
```

## Adding New Translations

1. Add new keys to both `src/locales/en/common.json` and `src/locales/vi/common.json`
2. Use the new keys in your components with `t('your.new.key')`

## Adding New Languages

1. Create a new folder in `src/locales/` (e.g., `src/locales/fr/`)
2. Add `common.json` with translations
3. Import and add the translations to `src/lib/i18n.ts`
4. Update the languages array in `src/components/language-switcher.tsx`

## Features

- **Automatic language detection** from browser settings
- **Persistent language selection** via localStorage
- **TypeScript support** with type-safe translation keys
- **Fallback language** (Vietnamese) when translations are missing
- **Dynamic document title** and language attributes
